# Външни инструменти

Проверени на 2026-10-29. Източниците са изтеглени като отделни Git checkout-и в `tools/`; няма създаден основен Git repository или публикация на приложението.

| Проект | Официален източник | Реална роля | Състояние |
|---|---|---|---|
| ILSpy | https://github.com/icsharpcode/ILSpy | Декомпилация и разглеждане на .NET assemblies | Изходният код е изтеглен. Компилиране и GUI не са проверени. Текущият checkout изисква .NET 11 SDK според `global.json`. |
| BAM | https://github.com/nsacyber/BAM | Метаданни от Windows updates, PE файлове и символи | Изходният код е изтеглен. Не е конфигуриран или изпълняван. README изисква допълнителни Windows Debugging Tools, 7-Zip, Python пакети и инфраструктура за updates/symbols. |
| GRASSMARLIN | https://github.com/nsacyber/GRASSMARLIN | Пасивна топология на ICS/SCADA мрежи | Изходният код е изтеглен. Проектът е архивиран според официалната GitHub страница. Не е изпълняван и не е включено мрежово прихващане. |
| Emissary | https://github.com/NationalSecurityAgency/emissary | Разпределен P2P workflow framework за обработка на данни | Изходният код е изтеглен. Не е компилиран или стартиран. Самият framework изисква специфични ServiceProviderPlace реализации за полезна работа. |

Официалният каталог на NSA е https://code.nsa.gov/ и препраща към проекти от `NationalSecurityAgency` и `nsacyber`. BAM и GRASSMARLIN не са в организацията `NationalSecurityAgency`.

Точните commit-и и действителните remote адреси са в `tools/catalog.json`. Изтеглен изходен код не означава инсталиран или тестван изпълним инструмент. Лицензите остават във всяко външно хранилище; кодът им не е вграден в ORBIT.

## Връзка с DJ приложението

ORBIT е собствена реализация чрез Web Audio. Посочените четири инструмента не са аудио двигател. GRASSMARLIN няма установена необходимост за DJ функциите. Emissary би имал смисъл при бъдеща разпределена обработка на големи музикални библиотеки, след доказана необходимост. ILSpy е приложим само към .NET компоненти; няма доказателство, че е подходящ за основния Serato executable. Не е извършвана декомпилация или модификация на Serato.

Cloud Environment skill е прегледан; работата се изпълнява локално на Windows. Не е установена прикачена управлявана cloud среда и не е извършено cloud внедряване. Наличните Exa, Chrome и локални инструменти са използвани; не са инсталирани допълнителни plugin-и и не са разширявани разрешения.
