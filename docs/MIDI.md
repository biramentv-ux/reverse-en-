# MIDI управление — версия 0.6

MIDI панелът приема Note On/Off, 7-bit CC и 14-bit pitch bend от един избран вход. Използва Web MIDI само след Connect, с `sysex:false, software:false`. Приложението не изпраща MIDI съобщения и не използва MIDI output. Самото отваряне на панела проверява наличност и състояние на разрешението, без да иска достъп.

## Използване

1. Свържи контролер и отвори MIDI → Connect MIDI. Разреши достъп в браузъра. При един наличен вход той се избира автоматично; при повече избери конкретния вход.
2. Избери действие или плъзгач в SOFTWARE TARGET. За безкраен CC енкодер избери неговото кодиране и стъпка. Обикновените потенциометри използват Absolute.
3. Натисни Learn control и задействай физическия контрол. Съобщението за научаване не изпълнява действието. При бутон отпусни и натисни отново.
4. Soft takeover задържа софтуерната стойност, докато физическият фейдър я достигне/пресече; активира се отново след промяна с мишката. Invert обръща посоката.
5. Mapping-ът се запазва в текущия браузър. Download mapping JSON създава резервно копие. Импортът проверява целия документ преди замяна. Максимум 128 контрола и 200000 знака. Непознати цели, невалидни стойности и дублиран физически контрол се отхвърлят.

Поддържаните цели са mixer master/crossfade, двата дека (play, start, sync, PFL, KEY, loops, hot cues, level, tempo, EQ, filter, ECHO/ROOM/reset) и sampler pads/stop/level. За недостъпни действия важат същите ограничения като на екрана: например KEY се сменя при спрян дек. Празният sampler pad не създава звук.

Disconnect освобождава избрания вход и запазва mapping-а. При изключване на устройството handler-ът се премахва; повторно свързване на същия избран ID възстановява входа. Ако браузърът даде различен ID, импорт с Use the selected MIDI input пренасочва mapping-а към новия избран вход. Няма универсални профили за конкретни модели, LED обратна връзка, SysEx, jog/scratch или MIDI clock sync.

## Доказателства и граници

- 30/30 Node теста, включително 16 MIDI проверки за parser, press/release, soft takeover, относителни енкодери, 14-bit mapping, атомарен импорт, избор на вход, отказ на разрешение, cancel и unplug/reconnect. Connection тестовете използват изрично подадени синтетични портове.
- 9/9 Chrome проверки през реалния studio UI: всеки MIDI target сочи към действителен контрол; crossfade, load, play/pause с release edge, tempo/display, FX/reset, PFL и sampler level. MIDI съобщенията са синтетични. Възпроизвеждането работи с реалния AudioContext, със заглушен master; това не е измерване на аудио изход или latency.
- Основният MIDI диалог е проверен за импорт, възстановяване след reload, отхвърляне на невалиден импорт без загуба на предишния mapping, премахване на тестовия mapping и реално изтегляне на валидно JSON резервно копие (`output/midi-export-0.6.json`). При проверката браузърът показва permission `prompt`; Connect не е натискан и физически контролер не е проверен.
- Резултати: `output/midi-verification-0.6.json`; панел: `output/orbit-midi-panel-0.6.jpg`.

За възпроизвеждане на UI проверките изпълни `npm.cmd run prepare:midi-qa`, отвори `/midi-qa.html` и Run MIDI UI checks. Страницата се генерира от текущия index и зарежда същия app.js; не подменя navigator и не иска MIDI разрешение. Използвай отделна тестова сесия: тя зарежда оригинален demo track и променя временно част от контролите.

Остава реална проверка с разрешен достъп, конкретен контролер, Learn, различните негови контроли, unplug/reconnect и дълга сесия. Web MIDI API основа: https://www.w3.org/TR/webmidi/ .
