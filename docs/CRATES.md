# Колекции и подготовка на сет — версия 0.8

Библиотеката вече има собствени crates: именувани колекции с подреден списък от песни. Един трак може да участва в повече колекции, без копиране на аудиото. Бутоните A/B/C/D зареждат песен и от избрана колекция.

## Работа с колекциите

1. New crate → име → Save crate. Имената са уникални без разлика между малки/главни букви, до 60 знака; български имена са допустими.
2. В All tracks маркирай песни или Select visible tracks. Избери Destination crate и Add selected. Новите песни се добавят в реда на избиране; повторно добавяне не създава дубликат.
3. Избери колекцията от страничната лента или Library view. Вторият избор е достъпен и на малък екран. Стрелките ↑/↓ променят реда. При търсене или сортиране стрелките са изключени; Crate order изчиства търсенето и връща записания ред.
4. Remove from crate премахва само избраните членства. Manage crate позволява преименуване и Delete crate. Аудиото, favorites, BPM, grid и cue точките остават в общата библиотека.
5. Backup crates → Download crates JSON изтегля имената, идентификаторите на песните и реда. Архивът не съдържа аудио, waveform, cues или MIDI настройки. В друг браузър аудио библиотеката трябва да е налична отделно; автоматично съпоставяне на преименувани файлове не се обещава.
6. Постави JSON в същия диалог и Import crates. Импортът слива по crate ID: съвпадащата колекция се обновява, останалите се запазват. Невалиден документ, дублирани имена/песни и надхвърлени лимити се отхвърлят преди запис.

Лимити: 100 колекции, 5000 идентификатора в една колекция и общ JSON каталог до 2 милиона знака, включително форматирането на изтегления архив. Така собствен валиден export остава допустим за import. Наличните песни са показани в списъка. Ако в архив има липсващи audio IDs, те се запазват и броят им се показва; при по-късна поява на същия ID песента се възстановява в съответното място.

## Съхранение

Колекциите са в localStorage `orbit-crates-v1` за текущия браузър и адрес; самото аудио остава в съществуващата IndexedDB библиотека. Не е нужна миграция или копиране на старите аудио записи. Ако storage е недостъпен/повреден при стартиране, показва се предупреждение и колекциите работят само за текущата сесия. Повреденият оригинален ключ не се презаписва. При неуспешен запис валидното предишно състояние се запазва.

Всеки запис чете актуалните данни. В поддържан браузър той се изпълнява под общ Web Lock, така че табовете на същия адрес да не презаписват независими промени едновременно. Другите табове обновяват колекциите чрез storage event. Без Web Locks има fallback с повторно прочитане; той не гарантира координация на действително едновременни записи. Основа: [W3C Web Locks API](https://www.w3.org/TR/web-locks/).

## Проверка

- 42/42 Node теста, включително десет за колекциите: ред, уникално членство, изтриване, независими записи, merge/валидация на backup, липсващ ID, quota/corruption и действително припокриващи се операции през наличния LockManager. Проверено е освобождаване на lock след отказ; callback е async за последователно поведение в браузъра и Node 25.
- Chrome UI: създаване, bulk add, две последователни премествания, търсене, BPM sort и възстановяване на crate order; reload; преименуване; премахване на членство при запазени три песни в All tracks; изтриване на друга попълнена тестова колекция; автоматично появяване/изчезване в друг таб; действително изтеглен JSON, отказ на невалиден backup, възстановяване на оригиналния ред и членство; липсващ audio ID, запазен след reload; зареждане на D от колекция.
- 12/12 допълнителни UI проверки на текущото приложение със синтетичен MIDI вход след добавянето на колекциите. Те включват A/C/D transport, C→D sync и Space за всички декове. Физически MIDI достъп не е искан.
- Доказателства: `output/crates-ui-0.8.json`, `output/crates-backup-0.8.json`, `output/midi-verification-0.8.json`, `output/orbit-crates-0.8.jpg`.
- При действителна emulation ширина 391 px колекцията е избрана през Library view, трите реда се показват, а body остава 375 px със scrollbar, без хоризонтално преливане. Screenshot: `output/orbit-crates-mobile-0.8.jpg`. Това не е проверка на физически телефон.
- Аудио графът не е променян в 0.8; последният му пълен резултат остава 41/41 от 0.7. Той не е нов продължителен аудио тест за тази версия.

В приложението е оставена една примерна колекция Opening set — demo с трите оригинални демо песни. Временната QA колекция и липсващият тестов ID са премахнати.

Остават автоматични колекции, вложени папки, drag/drop, обмен с външни DJ библиотеки, backup на цялата аудио библиотека и проверки с реални импортирани файлове. JSON за crates не замества тези възможности.
